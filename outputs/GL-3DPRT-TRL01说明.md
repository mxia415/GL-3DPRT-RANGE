# GL-3DPRT-TRL01 打印范围判定说明

版本：V1.1
日期：2026-08-03

`GL-3DPRT-TRL01.html` 将 TRL01 权威工程已验证的 50 mm 保守平滑 TCP 包络和九件 CAD/GLB 适配到 RANGE 项目。页面不重新采样、平滑或近似生成包络，也不改写设备模型合同。

## 权威资产

- 包络：`assets/trl01/envelope-v1-ypos-fullx-50mm-conservative.json`
- 九件模型与锁定清单：`assets/trl01/parts/`
- 包络来源：`/Users/ming/Documents/GL-3DPRT-TRL01`
- 算法合同：`trl01-ik-evidence-20260803-v1`
- 分辨率：50 mm
- 范围：世界 `Y>=0`，X `-3500..9000`、Y `0..4000`、Z `0..4000 mm`
- 显示网格：79,571 顶点、158,740 三角形
- 资产 SHA-256：`a26f553c80b513391035b1d8670f90ce28c28b670804babae1e167be5b880765`

设备禁区仍是源工程明确标注的等待实测假设：`X=-160..5800 mm、Y=-325..325 mm、Z>=0` 无限高。它不是现场测量值，也不能替代碰撞安全或制造放行。

## 固定打印姿态

页面设备模型严格使用本次用户截图参数：

- E1 = 2900 mm
- A1 = 0.0°
- A2 = -98.6°
- A3 = 59.2°
- A4 = 0.0°（永久固定）
- A5 = 129.4°
- A6 = 0.0°（固定）
- 工具方向：世界 `-Z`

九件原始 GLB 共用源工程锁定的 CAD 总装矩阵，再应用由权威 `computePose()` 计算的参考帧差，不对单件模型重新居中、缩放或补偿。

## 使用

请从项目根目录启动静态服务器后访问页面，不依赖互联网：

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4175/outputs/GL-3DPRT-TRL01.html`。Three.js、BVH、STL/GLB 加载器、包络和设备模型均保存在 `outputs/assets/`。

页面支持中英文、内接长方体判定、固定 L/W/H 最大贴合、STL 位姿与透明度、越界三角面红色显示、近似交线、设备/长方体显隐、尺寸标注、四个视角和响应式左栏。设备模型只作视觉参考，不参与范围判定。
