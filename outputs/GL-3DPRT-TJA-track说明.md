# GL-3DPRT-TJA 运动范围判定说明

版本：V3.0 · 2026-08-04 · ©Ming Xia

## 页面用途

TJA 页面在同一个工具中提供“轨道版”和“固定底座”两种设备形式。左侧“设备形式”下拉框会同步切换三维包络、设备模型、Z 范围、默认长方体、点判定、长方体完整判定和最大贴合逻辑。页面还支持中英文、STL 参考模型、交线显示及超范围三角面标记。

## 轨道版

轨道版使用 `codex://threads/019fa17d-a309-75a1-8fd1-7588ec91fcad` 中验证过的解析包络：

- X 滑台有效位置：`1000–23000 mm`
- 相对滑台中心的最大水平半径：`8130.3 mm`
- XY 外包络：沿 X 轨道扫掠得到的胶囊形区域
- TCP Z 范围：`-85–4415 mm`，总高度 `4500 mm`
- 中心禁区：沿 X 无限延伸、总宽 `1000 mm`、全高度贯通，即 `|Y|≤500 mm`

最终判定为：“点到 X 轨道线段的最短距离不超过 `8130.3 mm`”且 Z 位于 `-85–4415 mm`，并且点不在中心带内。长方体还会精确检查完整 Y 区间是否与中心带相交。三维包络从几何上拆为正、负 Y 两个连续可达体，中间保留贯穿全 X、全 Z 的空槽。

## 固定底座版

固定底座版的范围和模型来自 `codex://threads/019fa2cc-c191-7b93-91dc-26808f6c8e41`：

- 固定底座 J1 安装中心：世界坐标 `X=10512.635 mm`、`Y=0`
- XY 外包络：以安装中心为圆心、半径 `8130.3 mm` 的圆
- 页面采用的 TCP Z 范围：`0–4500 mm`
- 中心禁区：由固定平台 GLB 包围范围旋转 `45°` 后得到的全高度菱形
- 菱形相对安装中心的四个顶点为：
  - `(2708.607881, -0.000424) mm`
  - `(11.313638, -2697.294667) mm`
  - `(-2697.125527, 11.144498) mm`
  - `(0.168716, 2708.438741) mm`

最终判定为：“点到固定底座中心的距离不超过 `8130.3 mm`”且 Z 位于 `0–4500 mm`，并且点不在中心固定平台菱形内。长方体完整判定除角点和表面采样外，还会检查矩形投影与菱形的顶点包含和边线相交，避免长方体跨过禁区但采样漏判。三维圆柱包络的中心菱形从顶面、底面及侧面真实挖空。

## 最大贴合

- 轨道版在 `|Y|>500 mm` 的一侧执行贴合，不会跨越无限长中心带。
- 固定底座版在中心菱形的 `+Y` 一侧执行贴合，不会穿过固定平台。
- “固定L”“固定W”“固定H”三个按钮分别保留对应尺寸，搜索其余两个方向的最大可行组合。
- 两种形式的贴合结果都使用当前形式的完整长方体判定再次验证。

## 设备模型

轨道版使用用户提供的完整模型 `GL-3DPRT-TJA(track).glb`。原始文件为 `242.78 MB`，HTTP 部署文件 `outputs/assets/GL-3DPRT-TJA-track.glb` 经 SP-S 同类流程压缩为 `4.33 MB`；离线备用包使用 Meshopt。

固定底座版使用正式五分件模型：

- `TJA_00_FIX_PLATFORM.glb`
- `TJA_03_J1_COLUMN.glb`
- `TJA_05_Z_ARM1.glb`
- `TJA_06_J2_ARM2.glb`
- `TJA_07_J3_ARM3.glb`

HTTP 页面读取约 `9.64 MB` 的 Draco 部署资产。`file://` 页面从 `outputs/assets/TJA-fixed-model.js` 与 `TJA-fixed-model-2.js` 读取同一套模型的 Meshopt 备用数据。固定平台按正式世界姿态旋转 `45°`，其余四个分件使用固定版参考姿态。模型只用于视觉参考，不参与范围判定。

## 视觉与使用

- 轨道版继续使用约 `48 m` 的浅色低密度网格，默认从 `+X、+Y` 方向俯视长轨包络。
- 固定底座版切换为以 J1 安装中心为目标的较近默认视角。
- 两种形式的 Y、Z 轴均放在设备臂所在的中心平面；地面型号文字随形式切换。
- 点击“显示设备模型”按当前形式加载模型；若模型已显示，切换设备形式会自动换成对应模型。
- STL 仅作参考显示，不参与长方体判定。

## 离线分享

通过 HTTP 或网站访问时读取 `.glb` 和项目内 Draco 解码器；直接双击页面时读取 `TJA-track-model.js` 或 `TJA-fixed-model*.js` 中的 Meshopt 备用模型。分享时需要同时提供 TJA 页面和完整的 `outputs/assets` 文件夹。
