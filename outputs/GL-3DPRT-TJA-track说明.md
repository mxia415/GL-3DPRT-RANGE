# GL-3DPRT-TJA(track) 运动范围判定说明

版本：V1.1 · 2026-07-27 · ©Ming Xia

## 页面用途

TJA(track) 页面用于判断一个内接长方体是否完全落在 TJA 轨道打印机的轴限位可达空间内。页面支持中文和英文切换、导入 STL 参考模型、位置和姿态调整、交线显示、超出范围区域红色标记，以及设备模型显示。

## TJA(track) 包络数据

本页面使用 `codex://threads/019fa17d-a309-75a1-8fd1-7588ec91fcad` 中验证过的解析包络：

- X 滑台有效位置：`1000–23000 mm`
- 相对滑台中心的最大水平半径：`8130.3 mm`
- XY 包络：沿 X 轨道扫掠得到的胶囊形区域
- TCP Z 范围：`-85–4415 mm`，包络总高度 `4500 mm`
- TCP 包络包围盒：X `-7130.3–31130.3 mm`，Y `-8130.3–8130.3 mm`
- 中心禁区：沿 X 方向无限延伸、总宽 `1000 mm`、全高度贯通，即 `|Y|≤500 mm` 的所有点均不可达

最终判定为：“点到 X 轨道线段的最短距离不超过 `8130.3 mm`”且 Z 位于 `-85–4415 mm`，并且点不在 `|Y|≤500 mm` 的无限长、无限高中心带内。长方体除角点和表面采样外，还会精确检查其完整 Y 区间是否与中心禁区相交，避免长方体跨过禁区但采样漏判。

三维包络不是完整胶囊体叠加警示色，而是从几何上拆成 Y 正、负两个可达体，中间保留贯穿全 X、全 Z 的空槽；红色线框标示禁区在外部候选包络内的边界。

透明包络使用不受场景灯光影响的均匀透明材质，并采用双面单遍绘制，避免长包络正反面重复混合或三角面受光差异形成看似断开的竖向明暗带；这些显示设置不影响可达范围判定。

## 设备模型

设备模型改用用户提供的完整模型 `GL-3DPRT-TJA(track).glb`。原始文件为 `242.78 MB`，页面部署文件按 SP-S 相同流程处理：

`dedup → instance → palette → flatten → join → weld → simplify(20%, error 0.0005) → resample → prune → sparse → Draco（HTTP）/ Meshopt（离线）`

HTTP 部署文件使用 Draco 几何压缩，压缩后的 `outputs/assets/GL-3DPRT-TJA-track.glb` 为 `4.33 MB`。为避免浏览器在 `file://` 模式拦截本地 Draco WASM 解码文件，离线备用包改用 Meshopt 压缩，内含模型为 `6.67 MB`。原始副本保存在 `outputs/assets/raw/GL-3DPRT-TJA-track-raw.glb`。模型仅用于视觉参考，不参与可达范围判定；页面沿用正式 TJA 导入姿态，并使用稳定的半透明材质，不生成可能闪烁的共面边线。

## 视觉尺度调整

由于 TJA 包络长度约 `38.26 m`，页面专门调整了 3D 区域：

- 工作网格扩展至 `48 m`，中心移到 TJA 轨道中部；
- 默认视角改为从 `+X、+Y` 方向斜向俯视，朝向与用户提供的参考图一致；
- 默认视图目标位于 X `12000 mm`、Z `1800 mm`；
- 默认相机距离缩短为 `29000 mm`，使长轨包络在画面中的构图尺度接近参考图；
- 相机远裁剪面和缩放距离按长轨道范围扩大；
- X 轴沿整条轨道显示；Y、Z 轴及其刻度移到轨道中点 `X=12000 mm`，与设备臂所在的横截面重合；
- 设备标签移到长轨道下方并旋转 `180°`，避免与轨道和右下角视角控件重叠，同时使当前默认朝向下文字正置。

## 使用方法

1. 从首页选择 `TJA(track)`。
2. 点击“显示设备模型”查看压缩后的完整 TJA(track) 设备模型。
3. 直接输入 X/Y 位置，或拖动对应滑动条调整长方体位置。
4. 修改长度 L、宽度 W、高度 H，点击对应的“固定最大贴合”按钮查找中心禁区一侧的可行最大尺寸；贴合结果不会跨越中心禁区。
5. 导入 STL 后，可调整位置、缩放和旋转。STL 只作为参考显示，不参与长方体判定。
6. 点击“显示交线”显示 STL 与 TJA 包络边界的近似交线；超出范围的 STL 三角面会显示为红色，并在 3D 区域左上角提示。

## 离线分享

直接双击 `GL-3DPRT-TJA-track.html` 时，页面会使用 `outputs/assets/TJA-track-model.js` 中的 Meshopt 离线备用模型包，由 Three.js 的内置 Meshopt 模块解码，不再请求会被浏览器拦截的本地 WASM 文件；通过 HTTP 或网站访问时，会读取 `outputs/assets/GL-3DPRT-TJA-track.glb` 并使用项目内置 Draco 解码器。两个资源均由同一原始模型和相同简化参数生成；资源 URL 带版本标记，避免浏览器继续读取旧缓存。因此分享时需要同时提供 TJA 页面和 `outputs/assets` 文件夹。
