# GL-3DPRT-CRL01 打印范围判定说明

版本：V3.0 · 2026-08-04 · ©Ming Xia

## 页面基准

CRL01 页面以 `codex://threads/019fa625-2426-7922-84f6-3b109bb32fc6` 对应的 TRL02 V1.8 页面为基准。页面保留相同的布局、配色、输入控件、内接长方体、固定 L/W/H 最大贴合、STL 导入与交线、四种视角、中英文切换、模型显隐和状态读数。CRL01 没有 Long / Standard 两种打印头，因此不显示 Nozzle 切换框。

## 坐标与输入

- X、Y 轴的原点：A1 关节中心；
- 绿色 `Y+`：打印姿态下 A1 指向 A6 的水平投影方向；
- 红色 X 轴：与 Y 轴垂直，并同时显示 `X+` 与 `X−`；
- 蓝色 Z 轴：从 A1 正下方地面 `Z=0` 起，竖直向上；
- 长方体长度 L 沿绿色 Y 轴；
- 长方体宽度 W 垂直绿色 Y 轴；
- 长方体 X 中心偏移固定为 `0`，因此始终关于绿色 Y 轴对称；
- 长方体底面固定为 `Z=0`，向上展开。

默认长方体为：

- Y 轴中心位置：`1700 mm`
- X 中心偏移：`0 mm`
- L / W / H：`600 / 600 / 500 mm`

## 打印包络

包络数据来自 `codex://threads/019fac6a-f8cf-7891-95d9-706df3e5e0c4` 的 CRL01 权威 FK 与碰撞过滤结果：

- 总关节姿态：`334,880`
- TCP 在地面以上的理论姿态：`121,576`
- 碰撞过滤后通过：`68,250`
- 碰撞后采样范围：
  - X：`335.133…2638.679 mm`
  - Y：`-2088.679…2088.679 mm`
  - Z：`0.127…1534.359 mm`

网页使用通过姿态的 TCP 点，以 `40 mm` 网格、闭运算、有限膨胀和平滑生成连续隐式包络；显示曲面、长方体判定、STL 超范围标色和最大贴合共用同一个隐式场。它是基于离散 FK 证据的连续工程近似，不是连续空间极值的数学证明。

碰撞过滤使用参考任务中明确披露的保守代理模型：车体和电控柜使用扩张 AABB，机械臂和工具使用胶囊体，障碍物安全间隙为 `35 mm`，并检查主要非相邻连杆自碰撞。

## 设备模型

设备参考模型使用 CRL01 的八个原始分件：

- `crl01_00_fx_chassis.glb`
- `crl01_20_a1_robot_base.glb`
- `crl01_40_a2_upper_arm.glb`
- `crl01_50_a3_forearm.glb`
- `crl01_60_a4_wrist_roll.glb`
- `crl01_70_a5_wrist_bend.glb`
- `crl01_80_a6_flange.glb`
- `crl01_90_tool_tcp_assembly.glb`

八个分件共用同一个 CAD 米制坐标到 CRL01 世界毫米坐标的装配矩阵，没有逐件居中、缩放或手调。模型仅用于视觉参考，不参与长方体判定。

页面模型使用 CRL01 控制项目的正式打印姿态：

- A1：`0°`
- A2：`-80.736783°`
- A3：`150.120901°`
- A4：`0°`
- A5：`20.615882°`
- A6：`0°`

每个分件都从 CAD 标定姿态通过对应关节帧差值变换到打印姿态，打印轴严格指向世界 `-Z`。为匹配页面所需观察方向，设备、包络、长方体、网格、STL 与尺寸标注绕世界 Z 轴旋转 `180°`；坐标轴单独抵消场景旋转，并按 A1、A6 定义重新定位。默认视角使用绿色 Y+ 朝右下、X− 朝左下的斜俯视方向；判定所用的 CRL01 坐标数值保持不变。

## 资源与启动

- 页面：`outputs/GL-3DPRT-CRL01.html`
- 包络数据：`outputs/assets/CRL01-workspace.json`
- 离线包络：`outputs/assets/CRL01-workspace-data.js`
- 设备分件：`outputs/assets/CRL01-parts/`
- 模型包：`outputs/assets/CRL01-model-1.js` 至 `CRL01-model-8.js`

推荐从项目根目录启动：

```bash
python3 -m http.server 4174
```

然后打开：

```text
http://localhost:4174/outputs/GL-3DPRT-CRL01
```

HTTP 页面按需读取 JSON 包络；设备模型在点击后按顺序载入八个 JavaScript/Base64 模型包，每个包对应一个 GLB 分件。直接打开本地文件时使用同一套模型包。拆分后可避免 Cloudflare Pages 的大体积二进制响应或单个超大脚本在部分浏览器中出现正文读取超时。
每个模型包的慢网络保护超时为 10 分钟；下载完成后立即解析显示，不会固定等待。
