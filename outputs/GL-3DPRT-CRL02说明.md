# GL-3DPRT-CRL02 打印范围判定说明

版本：V3.0
日期：2026-08-04

## 页面用途

`GL-3DPRT-CRL02.html` 用于判定长方体或本地 STL 参考模型是否位于 CRL02 当前打印头的打印包络内。页面提供中英文、Standard / Long 打印头切换、XYZ 位置、长宽高、三种固定尺寸最大贴合、STL 缩放/旋转/透明度、近似交线、越界红面、设备模型和四种视角。

## 判定口径

- 页面直接加载最终批准的闭合平滑包络，显示网格和判定网格为同一份数据。
- 长方体检查 8 个角点及各表面约 100 mm 间隔采样点；任一点在网格外即判为越界。
- Standard 网格为 283,709 顶点 / 567,414 三角面，边界约 `X=-5595.841…5810.992、Y=0…4695.841、Z=0…3445.842 mm`。
- Long 网格为 237,183 顶点 / 474,362 三角面，边界约 `X=-5595.842…5810.993、Y=0…4695.842、Z=0…2445.842 mm`。
- 设备显示空区为 `X=-2335…1895、Y=-1469.927…1469.926、Z≥0`。页面把进入该区域的长方体或 STL 面视为打印范围外；它仅是已批准的设备显示空区规则，不是完整物理碰撞或安全净距结论。
- 两个平滑包络均为运动学显示/判定资产。可追溯的 50 mm 当前 IK 证据和生成参数保存在 `assets/crl02/evidence.json`，不能用页面截图反推或重新拟合几何。

## 大资源与离线策略

HTTP 模式按需加载当前打印头包络；点击“显示设备模型”后才加载十个独立 GLB（八个公共机械臂分件和两种打印头），每个下载、读取和解析步骤均使用 120 秒超时。部署模型使用 glTF Transform 4.4.0 的高精度 `KHR_mesh_quantization`：位置 16 bit、法线 12 bit、纹理坐标 14 bit，不执行减面。源模型与部署模型的顶点数、三角面数和 SHA-256 都记录在 `evidence.json` 中。

`file://` 模式按相同粒度加载 `assets/crl02/offline/` 中的独立脚本，并且离线包由压缩后的同一份 GLB 字节生成，不在首页一次性注入大包。最大轨道分件由 35.34 MB 降至 15.31 MB，对应离线脚本约 20.41 MB；所有单文件均低于 25 MiB。

## 使用与维护

推荐从仓库根目录运行：

```bash
python3 -m http.server 4174
```

然后打开 `http://127.0.0.1:4174/outputs/GL-3DPRT-CRL02.html`。生成或校验资产可运行：

```bash
node scripts/build-crl02-package.mjs
node scripts/test-crl02-range.mjs
```

生成脚本默认只从 `/Users/ming/Documents/GL-3DPRT-CRL` 读取权威数据；需要在其他机器重建时可设置 `CRL02_SOURCE_ROOT`。不要用该脚本修改 CRL01。
